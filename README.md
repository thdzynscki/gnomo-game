# 🍄 The Little Gnome Game

> A tiny forest adventure made with Python and Pygame. 🌿

Um jogo 2D para computador, inspirado na estética **Gnomecore** e **Goblincore**, onde você controla um pequeno gnomo explorando uma floresta de musgo, cogumelos e folhas de outono.

O projeto nasceu como um espaço separado de aprendizado, ao lado do site [The Little Gnome Library](#), e tem como objetivo aprender desenvolvimento de jogos com Python.

## 🌲 Sobre o jogo

Guie o gnomo pela floresta, colete cogumelos e descubra curiosidades sobre o mundo dos gnomos.

## 🎮 Controles

| Tecla | Ação |
|-------|------|
| ⬅️ ➡️ ⬆️ ⬇️ | Mover o gnomo |

## 🍄 Funcionalidades

- [x] Janela do jogo com loop principal (60 FPS)
- [x] Gnomo controlado pelas setas do teclado
- [ ] Limites da tela
- [ ] Cogumelos para coletar e contador de pontos
- [ ] Sprite de gnomo e cenário de floresta
- [ ] Balão de fala com curiosidades sobre gnomos

## 🛠️ Tecnologias

- Python 3
- Pygame

## ▶️ Como rodar

```bash
# 1. Criar e ativar o ambiente virtual
python -m venv .venv
.venv\Scripts\activate        # Windows
# source .venv/bin/activate   # Mac/Linux

# 2. Instalar a dependência
pip install pygame

# 3. Rodar o jogo
python main.py
```
